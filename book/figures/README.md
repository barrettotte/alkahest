# Figure fixture provenance

The SVG files in this directory are original Alkahest reference fixtures and
are dedicated to the public domain under CC0 1.0. Books may reuse or replace
them without a separate permission workflow.

| Asset | Role |
|---|---|
| `signal-chain.svg` | Ordinary captioned technical figure |
| `system-map-screen.svg` | Wide HTML and EPUB artwork |
| `system-map-print.svg` | Portrait Typst artwork |
| `data/response-time.csv` | Editable data behind the chart |
| `generated/response-time.svg` | Committed chart |
| `generated/voltage-divider.svg` | Committed circuit diagram |
| `generated/fischer-esterification.svg` | Committed reaction diagram |

The system-map variants contain the same information. The chart, circuit, and
reaction demonstrate the engine boundary: each book owns its editable source
and generation method, while Alkahest consumes a portable publication asset.
