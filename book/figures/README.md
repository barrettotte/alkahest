# Figure fixture provenance

All SVG files in this directory are original Alkahest acceptance fixtures,
created for this repository on 2026-08-16. They are dedicated to the public
domain under CC0 1.0 so books built from the template may reuse, modify, and
redistribute them without a separate permission workflow.

| Asset | Role |
|---|---|
| `signal-chain.svg` | Single captioned technical figure |
| `waveform-raw.svg` | Left subfigure in a comparison panel |
| `waveform-filtered.svg` | Right subfigure in a comparison panel |
| `system-map-screen.svg` | Color screen/EPUB variant of the full-width figure |
| `system-map-print.svg` | Patterned monochrome PDF variant of the full-width figure |
| `data/response-time.csv` | Canonical measurements for the generated response-time chart |
| `data/response-time.vl.json` | Evaluated Vega-Lite v5 candidate; not a publication input |
| `generated/response-time.svg` | Deterministic vector chart generated by `scripts/generate-graphs.py` |
| `generated/voltage-divider.svg` | Deterministic accessible circuit generated by `scripts/generate-circuits.py` |
| `generated/fischer-esterification.svg` | Deterministic accessible reaction generated by `scripts/generate-chemistry.py` |
| `candidates/voltage-divider-circuitikz.tex` | Evaluated CircuitikZ source; not a publication input |
| `candidates/voltage-divider-zap.typ` | Evaluated Zap source; not a publication input |
| `candidates/fischer-esterification-chemfig.tex` | Evaluated Chemfig source; not a publication input |
| `candidates/fischer-esterification-typed-smiles.typ` | Evaluated typed-smiles source; not a publication input |

The screen and print system maps have the same information, labels, reading
order, view box, and external alternative description. Color and pattern are
presentation variants rather than independent content.

The response-time CSV, Vega-Lite specification, generator, and SVG derivative
are original Alkahest fixtures created on 2026-08-19 and released under the
same CC0 1.0 dedication. `make check-graphs` regenerates the SVG in a temporary
directory and requires byte-for-byte equality with the committed derivative.

The voltage-divider generator, native comparison sources, and committed SVG
are original Alkahest fixtures created on 2026-08-19 and released under the
same CC0 1.0 dedication. Schemdraw itself remains MIT-licensed. `make
check-circuits` regenerates the selected SVG in a temporary directory and
requires byte-for-byte equality with the committed derivative.

The Fischer-esterification generator, native comparison sources, and committed
SVG are original Alkahest fixtures created on 2026-08-19 and released under
the same CC0 1.0 dedication. RDKit remains BSD-3-Clause licensed; Chemfig is
LPPL 1.3c and typed-smiles is MIT licensed. `make check-chemistry` regenerates
the selected SVG in a temporary directory and requires byte-for-byte equality.
