# Semantic icon sources

These small monochrome SVGs are original Alkahest assets distributed under the
repository's MIT license. Their filenames are implementation details; authors
use stable semantic names through the `alk-icon` shortcode registry in
`book/_extensions/alkahest-icons/registry.lua`.

Each SVG uses a 24 by 24 view box, no embedded text, the book's ink color, and
round line caps and joins. The shortcode supplies registry and fallback label
metadata; manuscript text carries the visible meaning.
